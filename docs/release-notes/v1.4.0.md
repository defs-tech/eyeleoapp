Windows build of EyeLeo, the macOS port feature set brought back to the original.

**This version is closed.** The tag is final and no further changes go into it. Work continues in
1.5.0.

Compared with 1.3.6:

- Exercises 8, 9 and 10 added; exercise 7 now animates.
- The neck and shoulders exercise uses two drawn frames instead of two moved layers.
- The long break cycles a full figure through four poses.
- A hydration reminder, and a tea timer with manual steeps.
- Red tea among the steeping schedules.
- Russian plural forms are fixed past one hundred.

The last two changes made inside this version:

- The tea hints in the tray menu are drawn in the same font they are measured in. They used to come
  out larger than the menu's own text and lose their first and last letters.
- The notice that ends a brewing session reads «Цикл проливов / завершен» on two lines instead of
  «<чай> готов», which claimed the tea was ready when the last steep had in fact run out, and did
  not fit the bubble.

Tea schedules live in tea.conf. The copy in the install folder is a template: on the
first run EyeLeo copies it to %APPDATA%\EyeLeo\tea.conf, and that copy is the one it
reads and the one to edit. Settings sit beside it in the same folder.

Attention: the assets are loaded relative to the working directory, so the program must
be started from its own folder.
