Bug fixes over 1.4.0. The tag is final; work continues in 1.5.0.

- The notice that ends a brewing session reads «Чай спился» on one line. In 1.4.0 it was two lines
  and the second was cut off.
- A sound now plays at the end of every steep, the last one included. It is a system sound, so nothing
  is shipped to make noise: Windows plays its own "notification" event, the macOS analogue is the
  "Submerge" sound from System Settings, and both follow the "Enable sounds" setting that was already
  there and had nothing to do with tea.
- tea.conf in the user profile now gets the teas a later version introduced appended to it. A tea
  missing from the file was already working, on the built-in schedule, but the file the user is told to
  edit did not mention it, so editing it appeared to have no effect.

Tea schedules live in tea.conf. The copy in the install folder is a template: on the
first run EyeLeo copies it to %APPDATA%\EyeLeo\tea.conf, and that copy is the one it
reads and the one to edit. Settings sit beside it in the same folder.

Attention: the assets are loaded relative to the working directory, so the program must
be started from its own folder.
